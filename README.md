# Paper Atlas - Vibrant & Expanded Map Edition
Developed for Academy of Computer & Information Sciences (Morris County School of Technology)
Authors: Saatwik Koni & Kenji Keller

## Key Upgrades
1. **Packed Map with 18+ Locations**: Covers real/realistic biotech companies in Morris County (Denville, Morristown, Morris Plains, Parsippany, Randolph, Whippany, East Hanover) and nearby NJ hubs (Bridgewater, Nutley, Piscataway, New Brunswick, South Plainfield).
2. **Vibrant & Friendly Aesthetics**: High-energy colors, glowing gradient buttons, card hover effects, clean typography (`Outfit` & `Plus Jakarta Sans`), and rounded UI cards.
3. **Official Paper Atlas Logo**: Vector SVG pin with base ripples and inner rings.
4. **Colorblind Accessibility**: Pins and legend chips feature mandatory color codes and custom icons (`fa-briefcase`, `fa-id-badge`, `fa-award`, `fa-sun`, `fa-graduation-cap`).
5. **Full Feature Set**: Viewport Hero Map, Glass Search Panel, Live Specs Banner, Transit Directions Planner, AI Chat Assistant with quick prompt buttons, and Job Overview Dialog.

## How to Run in VS Code
1. Extract `paper_atlas_vibrant_edition.zip`.
2. Open the extracted folder in VS Code (`File` > `Open Folder...`).
3. Right click `index.html` and select **Open with Live Server** (or double click `index.html` to open in any browser).
